# СКТО | Дневник конькобежца (PWA)

Спортивный дневник для спортсменов и тренеров Союза конькобежцев Тульской области.
Работает на iPhone и Android, устанавливается на главный экран, после первой загрузки работает без интернета.
Все данные хранятся **только на телефоне** (IndexedDB). Серверов, регистрации и платных сервисов нет.

## Состав комплекта
- `index.html` — приложение (дневник, обмен результатами, детализация кругов, рекорды, копии)
- `manifest.webmanifest` — описание приложения для установки
- `sw.js` — service worker (офлайн-режим и обновления)
- `icons/` — иконки (из утверждённого варианта № 3): `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-32.png`, `favicon.ico`

Все пути относительные, поэтому комплект работает и в подпапке (адрес вида `https://имя.github.io/skto-diary/`).
Файлы нужно выкладывать **в одну папку**, не меняя структуру.

## Размещение на GitHub Pages (бесплатно)
1. Зарегистрируйтесь на https://github.com (бесплатно) и войдите.
2. Нажмите «+» → **New repository**. Имя, например, `skto-diary`. Выберите **Public** → **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Распакуйте ZIP на компьютере и перетащите **содержимое** папки (`index.html`, `manifest.webmanifest`, `sw.js` и папку `icons`) в окно GitHub. Нажмите **Commit changes**.
   - Если папка `icons` не загрузилась перетаскиванием, откройте её на компьютере, выделите все файлы и перетащите их в окно GitHub после ввода `icons/` в строку имени файла (или используйте GitHub Desktop).
5. Откройте **Settings → Pages**. В разделе **Build and deployment → Source** выберите **Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
6. Через 1–3 минуты вверху страницы Pages появится ссылка вида `https://ВАШ-ЛОГИН.github.io/skto-diary/`. Откройте её на компьютере и на телефоне. Эту ссылку можно отправлять спортсменам и тренерам.

### Альтернатива: Cloudflare Pages (бесплатно)
Cloudflare Dashboard → Workers & Pages → Create → Pages → Upload assets → загрузите папку с файлами → Deploy. Ссылка вида `https://имя.pages.dev`.

## Установка на телефон
**iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран Домой» → «Добавить».
Chrome и другие браузеры на iPhone: «Поделиться» → «На экран Домой»; если пункта нет, откройте ссылку в Safari.
**Android (Chrome):** открыть ссылку → кнопка «Установить приложение» в разделе «Установить» дневника или меню ⋮ → «Установить приложение».
**Яндекс Браузер и другие:** меню → «Установить» / «Добавить на главный экран» (название зависит от версии); если нет, откройте ссылку в Chrome.
В самом дневнике есть раздел «Установить» с такой же инструкцией (скрывается, когда приложение уже установлено).

## Как выпустить обновление
1. Замените `index.html` (и другие файлы) на новые в репозитории.
2. В файле `sw.js` измените строку `const VERSION = '2.0.0';` на новую (например, `'2.0.1'`). **Без этого пользователи не получат уведомление.**
3. Подождите 1–3 минуты. При следующем открытии у пользователей появится сообщение «Доступно обновление» → кнопка «Обновить». Перезагрузка выполняется только по нажатию, незавершённая форма не прерывается.
4. Данные пользователей (IndexedDB) обновление не затрагивает.

## Резервные копии
«Копии» → «Сохранить резервную копию» создаёт файл `skto-diary-ГГГГ-ММ-ДД.json`. Его можно отправить в Telegram.
Восстановление: «Копии» → выбрать файл → «Заменить базу данными из файла». Перед заменой можно сделать копию текущих данных.
Браузер может удалить данные сайта при очистке памяти или долгом неиспользовании, поэтому периодически сохраняйте копию.
Резервная копия (вся база) и «Обмен результатами» (выбранные записи) — разные функции.

## Ограничения
- Синхронизации между устройствами нет: переносить данные нужно файлом (копия или обмен результатами).
- Данные в разных браузерах и в установленном приложении хранятся отдельно друг от друга. Установленное приложение — отдельное хранилище: если вы сначала вели дневник в браузере, а потом установили приложение, перенесите данные через резервную копию.
